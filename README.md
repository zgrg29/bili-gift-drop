# Bili Gift Drop

B 站直播礼物掉落工具，为 OBS 提供透明的礼物特效叠加画面。

项目当前处于初始化阶段，尚未实现直播间连接或特效。

## 目标

主播输入直播间号后，接收真实送礼事件，将对应的礼物图片掉落到直播画面中，并根据礼物金额和数量调整效果。主播通过本地控制面板配置效果，将工具提供的地址添加到 OBS「浏览器」源。

## 第一版：礼物掉落

- 全局支持简体中文、日本語、English；设置中可切换并保存语言，后续功能同步提供三语文案。
- 接收礼物 ID、名称、数量、单价及金额信息。
- 动态获取和缓存礼物图片；遇到未知礼物时尝试刷新资料，避免仅依赖随软件打包的固定图库。
- 实现透明背景下的下落、旋转、碰撞、弹跳、堆积和定时消失。
- 可配置掉落区域、图片尺寸、数量、停留时间及物理参数。
- 支持金额分档；明确区分礼物单价、赠送数量和整笔总金额。
- 提供并发与数量上限，避免大量送礼导致画面拥堵或性能下降。
- 提供模拟送礼、一键清空和配置保存功能。
- 处理断线重连、重复事件和连击消息，避免重复计算礼物。

金额规则的具体默认值，在效果预览和实际事件字段验证后确定。免费礼物与盲盒礼物的金额口径需单独明确。

## 后续：Super Chat（醒目留言）

- 显示昵称、金额与可选的留言正文。
- 优先采用接收事件中提供的有效起止时间或持续时长；缺失时再使用经过核实的金额时长规则。
- 多条 SC 独立计时，明确排布和溢出行为。
- 主播可在与 OBS 画布同比例的预览中拖动位置、调整尺寸并保存布局。

## 初步架构

1. B 站接入层：连接直播间，将平台消息转换为统一事件。
2. 礼物资料层：获取图片和资料，管理缓存与未知礼物刷新。
3. 规则层：计算金额分档、大小、数量与存活时间。
4. 本地服务：向控制面板和 OBS overlay 传递事件与配置。
5. 显示层：透明 overlay 渲染礼物物理效果，后续增加 SC 组件。

技术栈将在接入方案和物理渲染方案验证后确定。
