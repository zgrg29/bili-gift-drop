# Bili Gift Drop v0.5.0 — 醒目留言区域滚动（Preview）

Release tag: `v0.5.0`

Version: `0.5.0`

Release type: **Pre-release / 预览版**

## 简体中文

- 取消醒目留言最多显示3条的限制：全部仍有效的留言按接收顺序参与展示，继续保留最新100条作为容量保护。
- 按区域高度容纳卡片，默认从设定位置延伸至画面底部。区域高度可调10%–100%，实际高度不会越过屏幕底部。
- 内容放得下时保持静止；超出区域后缓慢上下往返滚动，两端各停留2秒。速度可设0–120画布像素/秒（基于1920像素画布宽度），默认20；0停止自动滚动。预览按比例缩放速度。
- 鼠标悬停或键盘聚焦卡片时暂停滚动，方便点击折叠/展开；到期计时不暂停。显示变化不再每秒重建相同卡片，保持平滑滚动与焦点。
- 高度、速度随现有配置自动保存、同步到OBS并在重启后恢复；新增文案支持简体中文、日语、英语。
- SC默认开启，不显示倒计时，保留平台事件的独立到期时间与颜色；语言切换、折叠、暂停滚动都不延长有效期。

## 日本語

SCの3件表示制限を撤廃し、有効なメッセージを受信順に表示します（最新100件まで保持）。表示領域の高さは10%–100%で設定でき、画面下端を越えません。初期値は配置位置から画面下端までです。収まる場合は静止し、超過時のみゆっくり上下に往復、両端で2秒停止します。速度は1920ピクセル幅のキャンバス基準で0–120ピクセル/秒、初期値20、0で停止。ホバー・フォーカス中はスクロールを一時停止しますが有効期限は進みます。高さ・速度は自動保存してOBSに同期し、再起動後も復元します。SCは初期設定で有効、カウントダウンは非表示です。

## English

Removes the three-card SC display limit. All active messages participate in arrival order, retaining the latest 100 for capacity protection. Region height is adjustable from 10% to 100% and clamped to the screen bottom; the default extends from the configured position to the bottom. Content stays still when it fits, otherwise scrolls slowly back and forth with a two-second pause at each end. Speed is 0–120 canvas pixels/second at 1920-pixel canvas width, default 20; 0 stops automatic scrolling. Hovering or focusing a card pauses motion for interaction, without pausing expiry. Height and speed save automatically, sync with OBS and survive restart. SC remains enabled by default and shows no countdown. All new UI supports Chinese, Japanese and English.

## 安装 / インストール / Installation

关闭旧服务，解压 `BiliGiftDrop-v0.5.0-windows-x64.zip`，运行EXE。配置自动补充新设置并保留原有选择。Windows x64，无需另装Node.js，附SHA256SUMS.txt。

旧サービスを終了し、ZIPを展開してEXEを起動します。設定は保持されます。Node.jsは不要です。

Stop the old service, extract the ZIP and run the EXE. Existing settings are retained. No separate Node.js installation is required.

真实付费SC/各金额事件颜色、OBS内交互、长期直播与全新Windows环境仍待实机验收。未签名预览构建。保留最新100条仍可能在极端数量或较慢速度下无法于到期前读完全部留言；不会为滚动延长平台有效期。

実際の有料SC・色・OBS内操作・長時間運用・新規Windows環境は未検証です。署名なしプレビューです。大量のメッセージや遅い速度では、すべてを読む前に期限が切れる場合があります。スクロールのために期限は延長しません。

Real paid SC events/colors, interaction inside OBS, long-running live use and a clean Windows environment remain unverified. Unsigned preview. Heavy volume or slow scrolling can still prevent every message being read before expiry; scrolling never extends platform lifetimes.
