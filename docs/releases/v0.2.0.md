# Bili Gift Drop v0.2.0 — 礼物高峰保护（Preview）

Release tag: `v0.2.0`

Version: `0.2.0`

Release type: **Pre-release / 预览版**

## 简体中文

- 新增送礼高峰保护：默认每秒最多生成 12 个图标，最多暂存 32 组、每组 40 个视觉副本，待生成效果超过 1.5 秒即丢弃，避免积压礼物雨。最近记录保留平台原始数量，视觉合并不改变送礼金额与数量。
- 同时限制图标数量和估算面积：默认最多 120 个、估算占掉落区域 15%，面积可设 1–30%。旋转图标外接方形面积求和是保守预算，不代表实际像素遮挡率。
- 拥挤时旧图标提前淡出，限制每秒生成数；缩小上限时必要的旧对象立即移除。
- 新增掉落区域位置和尺寸设置（百分比），画面严格裁切在指定区域内；预览显示当前图标数、估算面积与待生成数量。
- 低于单价门槛的真实礼物在查图前过滤，仍进入最近记录；优化空间网格碰撞、图片缓存与失败退避、最近记录刷新频率。
- 未知礼物目录查询共享进行中的请求，失败后间隔重试；保留动态图片适配，无需为兼容接口下新增的礼物逐个写代码。
- 所有新增设置和状态支持简体中文、日本語、English，设置可保存，语言切换保留画面状态。

使用方式：下载版本 ZIP 并解压，运行 `BiliGiftDrop-windows-x64.exe`，保持命令行窗口打开。在 OBS 添加 1920×1080 浏览器源，地址见面板。
升级：先关闭旧服务，再替换 EXE；现有设置保留，新设置自动补默认值。
建议只下载本次带版本号 ZIP，并用 `SHA256SUMS.txt` 校验。

## 日本語

ギフト集中時の生成レート・待機キュー・個数・推定面積を制限し、古いギフトを早めにフェードアウトします。落下領域の位置とサイズを保存でき、プレビューで個数と待機数を確認できます。既定は毎秒 12 個、最大 120 個、領域の推定面積 15%、生成待ちは 1.5 秒で破棄されます。単価フィルター、画像キャッシュ、近傍衝突判定も改善しました。三言語に対応しています。

ZIP を展開して EXE を起動し、コンソールを開いたままにしてください。更新前に旧サービスを終了します。設定は引き継がれます。

## English

Adds bounded gift bursts (12 icons/second by default), a short pending queue (1.5-second expiry), count and estimated-area budgets (120 icons and 15% of the drop region by default), early fading under crowding, configurable drop-region coordinates and dimensions, and preview statistics. Optimizes early price filtering, nearby collision checks, image caching/backoff, and history refreshes. New settings and status messages support all three languages and persist across restarts.

Extract the ZIP and run the EXE; keep its console open. Stop the old service before upgrading. Existing settings are retained and new options receive defaults.

## 验收与限制 / 検証と制限 / Validation and limitations

- Automated rules, i18n consistency, bounded-storm and overlay integration tests pass. Windows EXE HTTP/SSE, embedded assets, duplicate launch and settings persistence are covered by local regression checks; see the repository acceptance log for results.
- 压力测试使用合成事件和模拟时钟，不代表长期直播性能或 OBS 帧率保证。VM 渲染测试不替代浏览器视觉验收。
- 本轮浏览器视觉验收受工具连接及 URL 识别限制未完成；OBS 实机、新 Windows 环境、全新上架礼物、连送及盲盒完整实测仍待做。可编辑金额档位和 SC 未实现。
- Browser visual QA, OBS, a fresh Windows environment and newly launched platform gifts remain unverified. Configurable monetary tiers and SC are not implemented. This is an unsigned preview build.
- 面积预算可减少遮挡，但不能识别人脸；请使用区域设置避开主播。匿名接入和新礼物图片可用性依赖 B 站接口兼容与网络状态。
