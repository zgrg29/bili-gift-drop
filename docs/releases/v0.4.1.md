# Bili Gift Drop v0.4.1 — 醒目留言默认开启（Preview）

Release tag: `v0.4.1`

Version: `0.4.1`

Release type: **Pre-release / 预览版**

## 简体中文

- 醒目留言（Super Chat）改为默认开启，新安装及缺少此设置的旧配置无需再手动打开。
- 用户已经保存的开关选择继续保留；手动关闭后，刷新、切换语言或重启不会重新开启。
- 位置自动保存、自动折叠与点击展开保持现有行为。卡片不显示倒计时，后台按平台有效期到期移除。

## 日本語

SC を初期設定で有効にしました。新規インストールと SC 設定のない旧設定に適用されます。保存済みのオン・オフ設定は保持し、手動でオフにした場合は画面更新・言語変更・再起動で再度オンになりません。位置の自動保存、折りたたみ・展開、非表示の有効期限タイマーの動作は従来どおりです。

## English

Super Chat is now enabled by default for new installations and older configurations without an SC setting. Existing saved choices are retained. Turning SC off keeps it off across refreshes, language changes and restarts. Layout autosave, collapse/expand and expiry behavior are unchanged; cards show no countdown.

## 安装 / インストール / Installation

关闭旧服务，解压 `BiliGiftDrop-v0.4.1-windows-x64.zip` 并运行 EXE。Windows x64，无需另装 Node.js。附 `SHA256SUMS.txt`，升级保留配置。

旧サービスを終了し、ZIPを展開してEXEを起動します。設定は保持され、Node.jsは不要です。

Stop the old service, extract the ZIP and run the EXE. Settings are retained; no separate Node.js installation is required.

## 验证与限制 / Validation

24 automated tests pass, covering default-on migration, saved-off preservation, language changes, SC and gift regressions. Windows EXE regression checks default-on startup, HTTP/SSE, SC synchronization, embedded sources and restart persistence.

真实付费 SC、各金额事件颜色、OBS 内交互、长期直播及全新 Windows 环境仍待实机验收。本版为未签名预览构建。

実際の有料SC・各金額の色・OBS内操作・長時間運用・新規Windows環境は未検証です。署名なしプレビューです。

Real paid SC events/colors, interaction inside OBS, long-running live use and a clean Windows environment remain unverified. This is an unsigned preview.
