# Bili Gift Drop v0.6.14 — B 站登录（Preview）

中文：控制台新增 B 站登录，支持手机客户端扫码登录，也支持手动粘贴 Cookie（一般只需 SESSDATA）。登录后会使用该账号的 Cookie 和 UID 连接直播间，B 站可能因此返回礼物观众的完整昵称；匿名连接不再作为唯一方式。界面会明确提示：「匿名连接时 B 站可能隐藏礼物观众的昵称和 UID，完整昵称通常需要登录。」登录凭据只在本机使用：默认只保存在内存，勾选「记住登录」后写入本机数据目录；不会出现在日志、状态 API、OBS overlay 或截图中，也不会发送到 Bilibili 以外的服务。登录成功后会重新连接当前直播间以应用登录状态；退出登录会回到匿名连接。

日本語：コンソールに B 站ログインを追加。スマホアプリの QR スキャン、または Cookie（通常は SESSDATA のみ）の貼り付けに対応。ログイン後はそのアカウントの Cookie と UID で配信ルームへ接続するため、B 站がギフト視聴者の完全な名前を返す場合があります。「匿名接続ではギフト視聴者の名前と UID が隠れる場合があり、完全な名前には通常ログインが必要」と明示します。ログイン情報は本機のみで使用し、初期設定ではメモリだけ、『ログインを記憶』を選ぶとローカルデータに保存。ログ、状態 API、OBS overlay、スクリーンショットには出さず、Bilibili 以外のサービスにも送りません。ログイン成功後は現在のルームへ再接続し、ログアウトで匿名に戻ります。

English: Adds Bilibili login to the control panel, with mobile QR login and manual cookie login (SESSDATA is usually enough). After login the app connects with that account's cookies and UID, so Bilibili may return full gift-viewer nicknames; anonymous access is no longer the only option. The UI states: "On anonymous connections Bilibili may hide gift viewers' names and UIDs; seeing full nicknames usually requires login." Credentials stay local: memory-only by default, or written to the local data directory when "Remember login" is checked. They never appear in logs, status APIs, the OBS overlay or screenshots, and are not sent anywhere except Bilibili. A successful login reconnects the current room to apply it; logout returns to anonymous access.
