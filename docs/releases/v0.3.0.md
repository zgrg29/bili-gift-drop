# Bili Gift Drop v0.3.0 — 自定义礼物尺寸（Preview）

Release tag: `v0.3.0`

Version: `0.3.0`

Release type: **Pre-release / 预览版**

## 简体中文

- 新增主播可保存的最小礼物尺寸、最大礼物尺寸和达到最大尺寸的金额；默认 50%、150%、100 元。
- 按本次礼物总金额线性缩放（普通礼物为单价 × 本次数量），达到设定金额后封顶，免费礼物使用最小尺寸。100% 为 1920 × 1080 画布中的 80 像素，尺寸范围 10%–400%。最大值低于最小值会自动校正。
- 保存后同步至 OBS overlay，对新收到的礼物生效；已有图标和待生成效果保留接收时尺寸。最低触发门槛仍按单价判断，区域与面积保护可进一步限制实际显示尺寸。
- 简体中文、日本語、English 文案同步维护，旧配置自动补默认值，升级保留配置，语言切换保留画面与队列。
- 延续 v0.2.0 的生成限流、短队列、数量/面积保护和掉落区域数值设置。SC 暂未开发。

下载 `BiliGiftDrop-v0.3.0-windows-x64.zip` 和 `SHA256SUMS.txt`。升级前关闭旧服务，解压并运行 EXE，无需另装 Node.js；保持命令行窗口打开。OBS 浏览器源使用面板地址，画布为 1920 × 1080。

## 日本語

- 最小サイズ、最大サイズ、最大サイズに達する金額を保存できます。既定は 50%、150%、100 人民元です。
- 今回の合計金額に比例して拡大し、設定額以上で上限に達します。無料ギフトは最小サイズです。100% は 1920 × 1080 のキャンバスで 80 ピクセル、設定範囲は 10%～400% です。
- 保存後の新しいギフトに反映されます。既存・待機中のギフトのサイズは維持されます。最低単価の判定と領域・面積制限も引き続き有効です。
- 三言語、設定の保存、旧設定の移行に対応。更新前に旧サービスを終了し、ZIP を展開して EXE を起動してください。Node.js は不要です。SC は未実装です。

## English

- Configure and save minimum size, maximum size and the amount that reaches maximum size. Defaults: 50%, 150% and CNY 100.
- Icons scale linearly with this event’s total amount and stop growing at the maximum. Free gifts use the minimum. 100% is 80 pixels on the 1920 × 1080 canvas; allowed range: 10%–400%.
- Saved changes apply to newly received gifts. Existing and queued gifts retain their size. Minimum unit-price filtering, region limits and area protection still apply.
- All three languages and migration from older settings are supported. Stop the old service before upgrading, extract the ZIP and run the EXE. No separate Node.js installation is needed. SC remains unimplemented.

## 验证与限制 / 検証と制限 / Validation and limitations

19 automated tests pass, including amount boundaries, configuration migration, three-language form submission and overlay draw sizes. Local Windows EXE regression covers configuration persistence across restart and embedded source consistency. Chrome verification passed for saving and reloading custom values and switching all three languages at a 390-pixel viewport; the new settings showed no horizontal overflow. Initial sandbox connection failures were resolved by running an isolated test service outside the sandbox. OBS, complete page visual QA, long-running live use and a clean Windows environment remain unverified. This unsigned build is a preview.
