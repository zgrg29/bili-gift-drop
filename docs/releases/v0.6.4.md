# Bili Gift Drop v0.6.4 — 礼物上限交给设置与恢复默认（Preview）

中文：礼物不再受后台固定上限限制。单个礼物的图标数不再最多 40 个，等待队列不再限制 32 组或等待超过 1.5 秒就丢弃，生成速率、图标半径和合并数量都以设置为准。画面数量上限、估算占区面积上限、每秒最多生成图标数和最大礼物尺寸也取消了原来的 200 个 / 30% / 30 个 / 400% 输入上限，输入多少就按多少生效（仍保留合理的最小值）。礼物设置新增「恢复礼物默认设置」；模拟上舰改为舰长、提督、总督三个按钮，共用月数输入。已上传素材和其它设置不受影响。极端数值会占用更多性能，请按需设置。

日本語：ギフトの固定的な上限を廃止しました。1 ギフトあたり最大 40 個、待機列 32 組・1.5 秒破棄、生成速度・半径・合算数の制限はなくなり、設定値がそのまま反映されます。画面数上限・推定面積上限・毎秒最大生成数・最大サイズの入力上限（200 個 / 30% / 30 個 / 400%）も撤廃し、入力した値で動作します（下限のみ維持）。ギフト設定に「ギフト設定を初期値に戻す」を追加し、大航海テストは艦長・提督・総督の 3 ボタンに変更しました。保存済み素材とその他の設定は維持されます。極端な値は負荷が増えるため、必要に応じて設定してください。

English: Removes the fixed backend caps on gifts: no 40-icon ceiling per gift, no 32-group queue or 1.5-second drop, and spawn rate, icon radius and merged counts now follow your settings. The object-count, area, spawn-rate and size inputs also no longer stop at 200 / 30% / 30 / 400% (minimums still apply). Gift settings gain "Restore gift defaults", and the subscription test now has Captain, Admiral and Governor buttons sharing one month input. Saved media and other settings are kept. Extreme values cost more performance, so set them as needed.
