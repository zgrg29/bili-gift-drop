# Bili Gift Drop v0.6.5 — 礼物尺寸按单价与大航海中心轴对齐（Preview）

中文：礼物图标大小现在只按单个礼物的单价决定。同一个礼物送 1 个还是 100 个，单个图标都一样大；数量只影响图标个数。最小/最大尺寸和“单价达到最大尺寸的金额”仍按设置生效，免费礼物使用最小尺寸。大航海（舰长/提督/总督）改为按同一条中心轴线对齐：替换某个等级的素材、素材比例变化后，区域会围绕中心轴缩放，而不是保持左边线。旧配置在首次打开控制面板时会自动把当前左边缘换算成中心点并保存，画面位置不会移动；设置里的“大航海中心位置”就是该中轴线的百分比。

日本語：ギフトのアイコンサイズは 1 個あたりの単価だけで決まるようになりました。同じギフトを 1 個でも 100 個でも 1 個の大きさは同じで、個数はアイコンの数だけを変えます。最小・最大サイズと「最大サイズになる単価」は設定どおりに反映され、無料ギフトは最小サイズです。大航海（艦長・提督・総督）は同じ中心軸で揃うようになり、素材の差し替えや比率の変化では中心を軸に拡大縮小します。既存設定はパネルを開いたときに現在の左端を中心へ換算して保存するため、表示位置は動きません。設定の「大航海の中心位置」がその中心軸の割合です。

English: Gift icons now size by the unit price alone. One or one hundred of the same gift share one icon size; quantity changes only the icon count. Minimum/maximum size and the unit price for maximum size still apply, and free gifts use the minimum. Great Voyage tiers (Captain, Admiral, Governor) align on one center axis, so replacing a tier's media or changing its aspect scales around the center instead of pinning the left edge. Existing layouts convert their current left edge to the center and save it on the first control-panel load, so nothing moves on screen; "Great Voyage center" is that axis percentage.
