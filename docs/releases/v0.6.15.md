# Bili Gift Drop v0.6.15 — 登录二维码显示修复（Preview）

中文：修复 B 站登录面板只显示原始登录链接、不显示二维码的问题。根因是本地静态服务没有为 `.js` 设置 JavaScript Content-Type，且响应带 `X-Content-Type-Options: nosniff`，浏览器拒绝执行 `qrcode.js`，面板于是落到“显示原始 URL”的兜底分支。现在 `.js` 按 `text/javascript; charset=utf-8` 提供，二维码正常生成。兜底也不再是可点击链接，只显示可选中的纯文本，避免误点后跳到 B 站外部登录页或被诱导下载第三方播放器。界面新增提示：请用 B 站手机客户端扫码，不要点击外部页面或下载第三方播放器。登录逻辑、Cookie 保存、历史/翻译功能不变。

日本語：ログイン画面が QR を表示せずログイン URL だけを表示する問題を修正。ローカル静的配信が `.js` に JavaScript の Content-Type を付けず、`X-Content-Type-Options: nosniff` のため `qrcode.js` が実行されず、URL 表示のフォールバックになっていました。現在は `.js` を `text/javascript; charset=utf-8` で配信し、QR を生成します。フォールバックもクリック可能なリンクをやめ、選択可能なテキストだけにしたため、外部ログインページや第三者プレイヤーのダウンロードへ誤遷移しません。画面に「B站スマホアプリでスキャンし、外部ページや第三者プレイヤーを開かない」と表示します。ログイン処理、Cookie 保存、履歴/翻訳は変更ありません。

English: Fixes the login panel showing only the raw login URL instead of a QR code. The local static server did not give `.js` a JavaScript Content-Type, and with `X-Content-Type-Options: nosniff` the browser refused to execute `qrcode.js`, so the panel fell back to the raw URL. `.js` is now served as `text/javascript; charset=utf-8`, and the QR code renders. The fallback is no longer a clickable link; it is selectable plain text, preventing accidental navigation to Bilibili's external login page or third-party player downloads. The UI now says to scan with the Bilibili mobile app and not open external pages or download third-party players. Login logic, cookie storage, history and translation are unchanged.
