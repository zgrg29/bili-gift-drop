# Bili Gift Drop v0.4.0 — 醒目留言与布局自动保存（Preview）

Release tag: `v0.4.0`

Version: `0.4.0`

Release type: **Pre-release / 预览版**

## 简体中文

- 新增醒目留言（Super Chat）独立开关，和礼物掉落共用透明 OBS overlay。默认关闭，设置中开启后显示仍有效的 SC。
- 设置页拖动布局框，或输入左侧、顶部、宽度；也支持方向键微调。数值停止输入约400毫秒后自动保存，拖动松开立即提交保存，同步到所有 overlay，无需点击保存。重启保留布局。
- 默认15秒自动折叠，0关闭自动折叠；点击预览卡片标题再次展开，并同步 OBS。OBS 中可通过浏览器源“交互”操作。卡片不显示倒计时，后台按原定到期时间移除。
- 优先使用平台事件的结束时间/时长及颜色；缺少时长时，按官方权益表补充：30–49元60秒，50–99元2分钟，100–499元5分钟，500–999元30分钟，1000–1999元1小时，2000元起2小时。缺少有效起始时间的消息跳过，缺失颜色使用通用样式。
- 多条SC分别计时，最多显示3条、保留最新100条。等待、折叠、关闭显示或切换语言均不延长有效期；同ID去重、平台删除同步，刷新恢复仍有效留言，服务重启不回放。
- 所有新增设置、提示和模拟内容支持简体中文、日语和英语，保留平台原始用户名和留言。

## 日本語

SC 表示の独立スイッチと位置・幅の自動保存を追加。枠のドラッグ、数値入力、矢印キーで配置し、数値は入力停止から約400ミリ秒後、ドラッグはマウスを離した時に保存します。初期設定ではSCは非表示、表示後は15秒で折りたたみ（0で無効）。見出しのクリックで再展開し OBS と同期、OBS ではブラウザソースの「対話」を使用。カウントダウンは表示せず、配信元の期限と色を優先します。期限情報が不足する場合のみ公式の金額別時間を使用し、有効な開始時刻がないメッセージはスキップします。最大3件表示・最新100件保持。待機、折りたたみ、非表示、言語変更で期限を延長しません。原文とユーザー名を保持し、重複排除・削除通知・画面更新時の復元に対応。サービス再起動では再生しません。

## English

Adds an independent SC switch and saved position/width. Drag the layout box, enter numbers, or use arrow keys. Numbers save after about400ms without input; releasing a drag submits immediately and synchronizes overlays. SC defaults off, with a15-second collapse delay when enabled (0 disables collapse). Click headings to expand and synchronize OBS; use browser-source Interact inside OBS. Cards show no countdown. Platform expiry/duration and colors take priority, with the official price-duration table as a fallback when a valid start time exists. Up to3 cards display and the latest100 are retained. Waiting, collapsing, hiding and language changes never extend expiry. Original names/messages are retained; duplicates and platform deletions are handled. Refresh restores active cards; restarting the service does not replay messages. All new UI supports Chinese, Japanese and English.

## 安装 / インストール / Installation

下载并解压 `BiliGiftDrop-v0.4.0-windows-x64.zip`，关闭旧服务后运行 EXE；配置自动迁移保留。Windows x64，无需另装Node.js，附 SHA256SUMS.txt。

旧サービスを終了してZIPを展開し、EXEを起動します。設定は保持され、Node.jsの追加インストールは不要です。

Stop the old service, extract the ZIP and run the EXE. Existing settings are retained; no separate Node.js installation is required.
