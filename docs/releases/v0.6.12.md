# Bili Gift Drop v0.6.12 — 历史礼物翻译与 SC 翻译按钮（Preview）

中文：本场直播礼物历史增加礼物名称翻译，默认开启。中文原名保留，日语界面显示日语译名和片假名读音，英语界面只显示英语译名、不做英文发音；只使用内置词典，未知礼物保持原名。历史工具栏新增「翻译礼物名称（含日语读音）」开关。每条 SC 留言旁新增「翻译」小按钮，点击后才调用 Chrome 内置 Translator API 翻译成当前界面语言，原文继续显示，再附上译文；翻译中、失败和浏览器不支持都有提示，不自动翻译 SC。翻译只发生在控制台历史，不写入磁盘；不使用 Cookie，也不调用外部翻译 API。

日本語：この配信のギフト履歴にギフト名の翻訳を追加（初期設定で有効）。中国語の原名を残し、日本語 UI では日本語訳と片仮名の読み、英語 UI では英語訳のみ（英語の読みなし）を表示します。内蔵辞書のみを使い、未知のギフトは原名のまま。履歴ツールバーに「ギフト名を翻訳（日本語の読み付き）」スイッチを追加。各 SC の横に「翻訳」ボタンを追加し、押した時だけ Chrome 内蔵 Translator API で現在の UI 言語へ翻訳します。原文は残し、訳文を下に表示。翻訳中・失敗・非対応の表示あり。SC の自動翻訳はしません。翻訳はコンソール履歴内だけで、ディスクに保存せず、Cookie も外部翻訳 API も使いません。

English: Gift-name translation is added to the stream gift history and enabled by default. The Chinese original is kept; Japanese UI shows a Japanese translation plus a katakana reading, while English UI shows the English translation only (no English pronunciation). It uses the built-in glossary only; unknown gifts keep their original name. A "Translate gift names (with Japanese reading)" switch is added to the history toolbar. Each SC gets a small "Translate" button; only after clicking does it use Chrome's built-in Translator API to translate into the current UI language. The original stays visible and the translation is appended; loading, failure and unsupported-browser states are shown. SC is never translated automatically. Translation is console-history only, not written to disk, and uses no cookies or external translation API.
