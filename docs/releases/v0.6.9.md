# Bili Gift Drop v0.6.9 — 本场直播礼物历史（Preview）

中文：控制台最下方新增可折叠的「本场直播礼物历史」，按观众汇总礼物、醒目留言（SC）和大航海。相同礼物自动累加数量和电池，不同礼物分开；同一等级大航海累加次数和月份，不同等级分开。每条 SC 的留言全文始终展开显示，不折叠。每位观众显示总电池，每条礼物、SC 和大航海也显示电池。默认只显示电池，可在「金额显示」切换人民币或日元；日元使用每日在线汇率并显示汇率日期，取不到时不编造固定数字。历史只记录真实事件，模拟送礼不计入；清空画面不会清空历史，另有「清空历史」按钮。历史保存在本次运行内，关闭服务后清空，不把 SC 留言写入磁盘。保留 v0.6.8 头像和既有配置规则。

日本語：コンソール最下部に折りたたみ式の「この配信のギフト履歴」を追加。視聴者ごとにギフト・スーパーチャット（SC）・大航海を集計します。同じギフトは数量とバッテリーを合算し、異なるギフトは分けて表示。同じランクの大航海は回数と月数を合算し、異なるランクは分けます。SC のコメントは常に全文表示し、折りたたみません。各視聴者の合計バッテリーと、各ギフト・SC・大航海のバッテリーを表示。初期値はバッテリーのみで、「金額表示」から人民元または日本円に切り替えられます。日本円は毎日のオンラインレートを使い、レートの日付を表示。取得できない場合は固定値を作りません。履歴は実際のイベントのみ記録し、テスト送信は含みません。画面クリアでは履歴を消さず、「履歴を消去」ボタンで消去します。履歴は今回の起動中のみ保持し、サービス終了時に消去。SC コメントはディスクに保存しません。v0.6.8 のアバターと既存設定ルールを維持。

English: Adds a collapsible "This stream's gift history" at the very bottom of the control panel, summarizing gifts, Super Chats (SC) and subscriptions by viewer. The same gift adds up its quantity and batteries; different gifts stay separate. The same subscription tier adds purchases and months; different tiers stay separate. Every SC message stays fully expanded and is never collapsed. Each viewer shows total batteries, and every gift, SC and subscription shows its batteries. The default display is batteries only; "Amount display" can switch to CNY or JPY. JPY uses a daily online rate with the rate date shown, and never invents a fixed number when unavailable. History records real events only; simulations are excluded. Clearing the screen does not clear history; a separate "Clear history" button does. History lives only for this run and is cleared when the service stops; SC messages are not written to disk. Includes v0.6.8 avatars and existing configuration rules.
