# Bili Gift Drop v0.3.1 — 设置自动保存（Preview）

Release tag: `v0.3.1`

Version: `0.3.1`

Release type: **Pre-release / 预览版**

## 简体中文

- 掉落设置的数值和免费礼物开关自动保存，无需点击保存按钮。停止输入约 400 毫秒后，将有效值持久化并同步至 OBS overlay。
- 输入为空、越界或不符合步长时不保存，避免把输入过程中的空值误当成 0。连续输入合并保存，配置更新不会覆盖待保存的输入。
- 保存失败显示错误提示，保留保存按钮用于重试。尺寸变化对新收到的礼物生效，现有画面、待生成效果和直播间连接保持。
- 新提示和尺寸说明同步支持中日英。

## 日本語

落下設定の有効な数値と無料ギフトのスイッチ変更は、入力停止から約 400 ミリ秒後に自動保存・反映されます。保存ボタンの操作は不要です。空欄や無効な値は保存せず、編集中の値を設定通知で上書きしません。失敗時はエラーを表示し、保存ボタンで再試行できます。サイズ変更は新しく受信するギフトに適用されます。

## English

Valid numbers and the free-gift toggle in Drop settings now save and apply automatically after about 400 ms without typing. No Save click is needed. Empty or invalid values are not saved. Incoming configuration updates preserve pending edits. Save failures show an error; the Save button remains available for retrying. Size changes apply to newly received gifts without clearing existing effects or disconnecting the room.

## 安装 / インストール / Installation

下载并解压 `BiliGiftDrop-v0.3.1-windows-x64.zip`，运行 EXE；升级前关闭旧服务，原配置保留。附 SHA256SUMS.txt。Windows x64，无需另装 Node.js。

更新前に旧サービスを終了し、ZIP を展開して EXE を起動します。設定は保持され、Node.js は不要です。

Stop the old service, extract the ZIP and run the EXE. Settings are retained; no separate Node.js installation is required.
