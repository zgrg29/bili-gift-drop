# Bili Gift Drop v0.6.2 — 大航海特效与统一布局编辑（Preview）

Tag: v0.6.2
Release type: Pre-release
Package: BiliGiftDrop-v0.6.2-windows-x64.zip

## 简体中文

从v0.5.0升级，新增大航海特效，并将礼物、SC和大航海统一到一个可编辑预览中。

- 大航海默认开启，显示观众头像、原始昵称、舰长/提督/总督及本次购买期限；任意月数显示对应文字，一次多月只播放一次。
- 每位播放8秒，按接收顺序排队，最多100位等待；满队提示并跳过新事件。关闭大航海、换房、清空会清除队列，重启不回放旧购买。
- 三级AI像素舰船默认素材，可分别替换PNG/JPEG/WebP/GIF/MP4/WebM，单文件32 MiB以内；视频静音循环。图片/GIF尺寸与视频元数据决定展示比例，头像昵称期限独立排在下方；支持最大100%请求宽度，高素材整体缩小以适应画面。
- 单一预览包含礼物绿色框、SC紫色框、大航海蓝色框。礼物/SC可移动并独立调整宽高，大航海按素材比例缩放；数字、鼠标和方向键操作自动保存。
- 三类效果各有透明度滑杆，默认100%；切换语言、修改布局或透明度不重置SC到期或上舰队列。
- 中日英三语说明、配置保存、旧配置默认值和Windows便携EXE同步更新。配置与素材保存在%LOCALAPPDATA%\BiliGiftDrop，升级前停止旧服务，替换EXE即可。

验收：31项自动测试、本机EXE隔离回归通过；已有浏览器移动/缩放、三语桌面和100×200竖版GIF原比例证据。真实上舰、真实付费SC/配色、OBS、完整三语窄屏、全部视频编码、长期直播和全新Windows环境仍待验收。缺头像用昵称首字，缺期限标记未知；匿名连接及平台字段完整性不作保证。未签名预览版。

## 日本語

v0.5.0からの変更：大航海を追加し、ギフト・SC・大航海を単一の編集プレビューに統合。

- 大航海は初期設定で有効。アバター、元の名前、ランク、今回の購入期間を表示。複数月の購入でも1回だけ再生。
- 1人8秒、受信順、最大100人待機。満杯時は通知して新規分をスキップ。無効化・ルーム変更・クリアで列を消去し、再起動後は過去分を再生しません。
- 各ランクに標準AIピクセル艦船。PNG/JPEG/WebP/GIF/MP4/WebM（最大32 MiB）で置換可能。動画は無音ループ。素材サイズ・動画メタデータから比率を自動計算し、視聴者情報を下に表示。要求幅は最大100%、縦長素材は画面内に収まるよう縮小。
- 緑はギフト、紫はSC、青は大航海。ギフト・SCは幅と高さを個別に変更、大航海は素材比率を維持。マウス、数値、矢印キーで編集して自動保存。
- 各不透明度スライダーは初期100%。言語・レイアウト・不透明度の変更で期限や再生列をリセットしません。三言語と設定保存、旧設定移行、Windows EXEに対応。
- 保存先は%LOCALAPPDATA%\BiliGiftDrop。更新前に旧サービスを停止してEXEを交換してください。

検証：31件の自動テストとEXE隔離回帰、一部ブラウザ操作・三言語デスクトップ・縦長GIFを確認済み。実際の上艦、有料SCと配色、OBS、完全な三言語狭幅レイアウト、全コーデック、長時間配信、新規Windows環境は未検証。情報不足時は名前の先頭文字・期間不明を表示。匿名接続・フィールド完全性は保証しません。署名なしのプレビュー版です。

## English

Changes since v0.5.0: adds Great Voyage subscriptions and combines gifts, SC and subscriptions in one editable preview.

- Subscriptions are enabled by default, displaying avatar, original name, tier and purchased duration. Multi-month purchases play once.
- Each viewer plays for 8 seconds in arrival order, with up to 100 waiting. Full queues skip new events with a warning. Disabling, changing room or clearing removes the queue; shutdown never replays old purchases.
- Default AI pixel ships for all three tiers. Replace each with PNG/JPEG/WebP/GIF/MP4/WebM up to 32 MiB; videos loop muted. Image/GIF dimensions and video metadata determine proportions, with viewer details below. Requested width supports 100%; tall content scales down to fit the canvas.
- Green gift, purple SC and blue subscription frames share one preview. Gift and SC width/height resize independently; subscription resizing follows media proportions. Mouse, number and arrow-key edits save automatically.
- Independent opacity sliders default to 100%. Language, layout and opacity changes preserve SC expiry and queue timing. Includes three-language UI, saved settings, migration defaults and a portable Windows EXE.
- Data stays in %LOCALAPPDATA%\BiliGiftDrop. Stop the previous service before replacing the EXE.

Validation: 31 automated tests and isolated local EXE regressions pass, with browser interaction, three-language desktop and portrait-GIF evidence. Real subscriptions, paid SC/colors, OBS, complete narrow layouts in all three languages, all codecs, long-running streams and clean Windows installations remain unverified. Missing avatars use name initials; missing duration is marked unknown. Anonymous access and complete platform fields are not guaranteed. Unsigned preview.
