English: Super Chat settings add "Disable Scrolling" (off by default) and "Newest SC position" (top/bottom, bottom by default). With scrolling disabled, no auto-scroll runs and the region updates directly in the chosen direction; the newest Super Chat always takes priority, and older cards beyond the region height leave the visible area while remaining in this run's data (still only the latest 100, never written to disk). Turning scrolling back on keeps the existing round-trip scroll, speed, hover/focus pause and auto-collapse; top mode only reverses the order while bottom mode keeps the arrival order. Both settings autosave, survive restarts, are reset by the SC restore-defaults button, and language changes never clear Super Chats. The existing SC rectangle and clipping are reused without a second canvas; a single card taller than the region shows its heading top and remains interactive.
