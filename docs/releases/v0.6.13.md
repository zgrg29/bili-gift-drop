# Bili Gift Drop v0.6.13 — 匿名礼物头像兜底（Preview）

中文：修复匿名连接下礼物观众「有头像 URL、但历史仍显示首字占位」的问题。实测部分礼物事件的 UID 为空、昵称被平台遮罩成「首字***」，但事件仍带 `face` 头像地址；现在即使 UID 为空，也会用事件头像缓存并更新对应观众，历史头像可以正常显示。昵称仍然无法通过公开 UID 查询补全，因为事件里没有 UID；历史会保留平台给的 `欠***` 这类遮罩名，不会再显示“未知观众”。如果需要完整昵称，只能通过登录/Cookie 或其他已授权数据源，当前版本仍不使用 Cookie。

日本語：匿名接続で「アバター URL はあるのに履歴が先頭文字の代替表示になる」問題を修正。一部のギフトイベントは UID が空で名前が「先頭文字***」に伏せられますが、`face` のアバター URL は残っています。UID が空でもイベント画像を保存して該当視聴者に反映するため、履歴のアバターが表示されます。UID がないため公開プロフィールで名前を補完することはできず、`欠***` のような伏せ名はそのまま残ります。「不明な視聴者」には置き換えません。完全な名前にはログイン/Cookie など別の許可済みデータが必要で、現行版は Cookie を使いません。

English: Fixes gift viewers showing an initial placeholder even though the event contains an avatar URL. In some anonymous gift events the UID is empty and the name is masked as "first character***", but the `face` avatar URL is still present. The history now caches that event face and updates the viewer even with an empty UID, so the avatar appears. The nickname still cannot be recovered through public UID lookup because the event has no UID; the platform-masked name such as `欠***` remains and is not replaced with "Unknown viewer". A full nickname requires login/cookies or another authorized data source; the current version still uses no cookies.
