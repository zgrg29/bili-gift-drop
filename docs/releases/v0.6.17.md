# Bili Gift Drop v0.6.17 — 登录自动保存（Preview）

中文：登录改为自动保存，不再需要勾选「记住登录」。扫码或手动 Cookie 登录成功后，凭据自动写入本机数据目录（`data/login.json`，未额外加密），下次启动保持登录；点「退出登录」即删除本机凭据并回到匿名。登录面板移除该勾选框，三语提示说明保存位置与删除方式。扫码/Cookie 解析、nav 校验、连接和昵称处理不变。

日本語：ログインを自動保存に変更し、「ログインを記憶」のチェックは不要になりました。QR または Cookie でログインに成功すると、認証情報は本機のデータフォルダー（`data/login.json`、追加暗号化なし）へ自動保存され、次回起動時もログイン状態が続きます。「ログアウト」で本機の認証情報を削除し、匿名に戻ります。ログイン画面のチェックボックスを削除し、3 言語の説明も保存場所と削除方法に合わせて更新しました。QR/Cookie の解析、nav 検証、接続、名前の処理は変わりません。

English: Login is now saved automatically; there is no "Remember login" checkbox to tick. After a successful QR or cookie login, credentials are written to the local data folder (`data/login.json`, unencrypted) and the next start stays logged in; "Log out" deletes the saved credentials and returns to anonymous access. The login panel no longer shows the checkbox, and the three-language text explains where credentials are saved and how to remove them. QR/cookie parsing, nav verification, connection and nickname handling are unchanged.
