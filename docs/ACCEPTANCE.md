验收日期：2026-10-24（Asia/Shanghai）。范围：本次对话的全部需求、调研、工程操作及后续功能约定。此报告评估当前成果，不把验收请求理解为立即实现全部后续功能。

## v0.3.1 自动保存增量验收

- 19 项测试通过；掉落数值和免费开关自动保存、400 毫秒防抖、无效输入保护、待编辑值不被配置广播覆盖及原有 overlay 行为覆盖通过。
- Chrome 不点击保存修改最小尺寸为 85%、满尺寸金额为 35 元，刷新仍保持。新增提示在中日英 390 像素窄屏可见、正常换行、无横向溢出；证据见 screenshots/autosave-*.png。
- Windows EXE 重建和回归通过，内嵌源码与当前工作区一致，HTTP/SSE、模拟、清空、配置重启与退出端口释放通过。发布材料为 v0.3.1，原 v0.3.0 保留。
- OBS、完整全页面视觉、长期直播及全新 Windows 状态未变。

## v0.3.0 自定义礼物尺寸增量验收

- 功能自动验收通过：最小/最大尺寸与满尺寸金额可保存，按规范化事件总金额线性缩放，免费取最小值、超额封顶。旧配置迁移、输入校正、最低单价规则、语言切换和已有图标尺寸保持均覆盖。19/19 测试通过，含 Canvas 绘制尺寸集成测试。
- Chrome 功能验收通过：75%/200%/25 元保存后刷新保持；390 像素视口切换 zh-CN/ja/en，新设置标签和输入框无横向溢出，设置值保持。三张截图见 screenshots/gift-size-*.png。没有将该局部检查推广为全页面视觉或 OBS 验收。
- Windows 包重建为 v0.3.0，EXE 回归通过，包括三语、本地 HTTP/SSE、重复启动、新尺寸配置重启恢复、内嵌源码一致性与端口释放。初次沙箱内测试因本地网络限制失败，沙箱外隔离运行通过。
- README、规划、日志和三语 Release notes 已同步；本轮提交并推送源码及 tag，用户自行发布 Release。OBS、长期实机、全新 Windows 和 SC 状态不变。

## v0.2.0 最新增量验收

已实现送礼高峰限流、短队列、数量/估算面积限制、拥挤淡出、掉落区域数值设置、预览统计、查图前单价过滤、空间网格碰撞及缓存退避。16 项规则、三语控制面板和 overlay 集成测试通过，包括 60 秒模拟画面/600 次突发事件，以及持续 60 秒合成风暴。旧章节中的“区域编辑未实现”现在仅适用于拖拽编辑，百分比数值设置已实现。

本次浏览器目视验收未完成：内置浏览器连接本地服务失败，Windows Computer Use 因无法可靠识别当前浏览器 URL 停止。没有据此推定三语窄屏或 OBS 通过；语言资源键/插值自动检查通过，语言切换保留对象及队列的集成测试通过。EXE 和发布包结果见 [本次日志](../log/2026-10-24-crowd-protection.md)。版本 `0.2.0`，作为预览包准备本地 tag 和三语 Release notes，未远程发布。

## 总体结论

当前是可运行的礼物掉落开发原型。真实 B 站礼物到浏览器画面的有限样本已验证，最低触发单价与当前三语界面具备使用基础。第一版整体尚未验收通过，主要缺少 OBS 实机验证、完整金额分档、区域定制和可靠性验证。SC在v0.4.0已实现并通过自动、浏览器及EXE预览验收；真实SC与OBS仍待验收。
