# 历史礼物名称翻译与 SC 翻译按钮（v0.6.12）

日期：2026-10-31（Asia/Shanghai）。范围：历史礼物的名称/日语读音翻译、每条 SC 的按需翻译按钮。

## 用户需求

- 礼物名称按界面语言翻译，原文保留，旁边括号显示译名。
- 日语界面加片假名读音；英文不做英文发音，直接跳过。
- 礼物名称翻译和读音默认开启，可用词典。
- SC 每条加一个小翻译按钮，点击后才翻译；原文保留并附译文。
- 不需要 SC 整句发音；SC 内容公开，不作为隐私阻塞。

## 实现

- 新增 `src/shared/gift-names.mjs`：常见礼物中文/日语/英语词典 + 普通话音译片假名。
  - `giftDisplayName(name, language, translation)`：
    - 中文界面：原名；
    - 日语：`原名（日语译名 / 片假名读音）`；
    - 英语：`原名 (English)`，不输出英文发音；
    - 未知礼物：原名；
    - 关掉翻译：原名。
  - 词条覆盖人气票、棒棒糖、小花花、粉丝团灯牌、薯条、辣条、生日蛋糕、小心心、玫瑰、干杯、小电视、亿圆等常见礼物。
  - 日语读音是普通话音译近似，不是官方读音。
- 配置新增 `giftTranslation`，默认 `true`；历史工具栏新增「翻译礼物名称（含日语读音）」复选框，自动保存。历史和「最近礼物」共用同一翻译设置。
- 每条历史 SC：
  - 只在检测到的原文语言与当前界面语言不同时显示「翻译 / 翻訳 / Translate」小按钮；
  - 点击后调用 Chrome 内置 `Translator` API（`Translator.availability`/`create`/`translate`），按当前界面语言翻译成对应的 `zh`/`ja`/`en`；
  - 先显示原文，翻译中显示「翻译中…」，完成后在下方追加「译：...」；
  - 再次点击可收起译文；失败显示「翻译失败」并可重试；浏览器不支持时显示明确提示；
  - 不自动翻译 SC，不调用外部翻译 API，不使用 Cookie；
  - 译文仅保存在控制台内存，不写盘；换房/清空历史时清空翻译状态。
- 翻译按语言缓存在内存中（`语言:SC id`），语言切换后按新目标语言重新翻译。
- 未改变：SC 卡片原样式、OBS 画面、历史聚合、电池、头像、UID 昵称补全、金额显示和每日汇率。

## 未验收与边界

- Chrome 内置 Translator API 需要支持该 API 的 Chrome 版本，可能首次下载模型；OBS 内置浏览器通常不支持，译文只在控制台历史显示，不会自动出现在 OBS 画面。
- 词典只覆盖已收录的常见礼物；未知礼物保持原名，不自动机翻。日语片假名是近似普通话音译，不是官方读音；英文界面不提供英文发音。
- 真实直播 SC 翻译、非 Chrome 浏览器、OBS、完整三语窄屏、全部视频编码、长期高峰和全新 Windows 仍未验收。
